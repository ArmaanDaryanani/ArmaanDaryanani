## Huntsman AI · Founder · March 2026 to present

[gethuntsman.com](https://gethuntsman.com)

Huntsman lets people describe a trading strategy in plain English and turns it into human-readable rules that agents run in practice accounts, with risk limits on every agent. Huntsman has applied to register with the SEC as an investment adviser.

- An LLM compiles each idea into a typed rule; a deterministic engine, not the model, executes it
- 48 rule-based agents across stocks, ETFs and crypto, in practice accounts
- Native Swift/SwiftUI app and TypeScript/PostgreSQL backend with SnapTrade, Alpaca and OpenRouter integrations; app submitted to the App Store
- Development runs through AI coding agents under release gates: founder sign-off, an LLM evaluation gate and 110 guardrail and adversarial tests
